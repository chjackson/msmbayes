# The 'msmbayes' package for Bayesian multi-state modelling of intermittently-observed data

For an introduction to and overview of the `msmbayes` package, and full
documentation, see

<http://chjackson.github.io/msmbayes>.

For more resources on multi-state modelling, see the [`msm`
package](http://chjackson.github.io/msm) and its documentation.
